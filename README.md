# Linux Virtual Machine Setup Using VirtualBox

## 📌 Project Overview
This project documents the process of creating and configuring a Linux virtual machine using Oracle VM VirtualBox. The assignment is designed to develop practical knowledge of virtualization, Linux installation, and basic system configuration.

## 🎯 Objectives
- Understand the concept of virtualization.
- Install and configure Oracle VM VirtualBox.
- Create a virtual machine for running Linux.
- Configure the virtual machine's hardware resources.
- Install Linux and verify that the system works correctly.
- Gain hands-on experience with a Linux operating environment.

## 🛠️ Tools and Technologies
- **Host Operating System:** Windows
- **Virtualization Software:** Oracle VM VirtualBox
- **Guest Operating System:** Linux (Kali Linux, if applicable)
- **Computer:** Personal computer or laptop

## ⚙️ Tasks Performed
1. Installed and opened Oracle VM VirtualBox.
2. Created a new virtual machine.
3. Configured the virtual machine's RAM, processor, and storage.
4. Selected the appropriate Linux ISO image or virtual machine image.
5. Configured the virtual machine's network and system settings.
6. Installed or booted Linux in the virtual environment.
7. Tested the virtual machine to verify successful operation.

## 📚 What I Learned
- The fundamentals of virtualization and virtual machines.
- How to allocate hardware resources to a virtual machine.
- The basic process of setting up a Linux environment.
- The importance of system configuration and troubleshooting.
- How Linux virtual machines can support future cybersecurity and system administration practicals.

## 🚀 Conclusion
This assignment provided hands-on experience in setting up a Linux virtual machine using VirtualBox. It establishes a foundation for further learning in Linux administration, networking, and cybersecurity.
